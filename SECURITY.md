# Security Policy  

## Reporting Security Issues  

If you believe you've found a security vulnerability in this project, please **do not create a public issue**. Instead, email us at **<security@unraid.net>** with:  

- A clear description of the issue
- Steps to reproduce the vulnerability
- Relevant logs, screenshots, or proof-of-concept code
- Any known or potential impact

If you would like to sign your submission digitally, you can find our pgp key here:
<https://unraid.net/.well-known/security.txt>

For details on next steps in the process please see:
<https://unraid.net/policies>
